Punto de entrada a la documentación de análisis, diseño, decisiones y resultados del proyecto (v1.0 implementada). Cada documento existe en Markdown (fuente, versionado junto al código) y en HTML navegable (generado con scripts/build_docs.py).

Decisiones de arquitectura (ADR)#

ADR Decisión Markdown
ADR-001 · PostgreSQL PostgreSQL 18 como almacén principal (upsert atómico, índices con INCLUDE, citext, xmin). 0001-postgresql.md
ADR-002 · Clean Architecture Cuatro capas con dependencias hacia el dominio, CQRS liviano sin mediador, límites verificados por tests. 0002-clean-architecture.md
ADR-003 · Anti-cheat API Key + HMAC-SHA256, nonce idempotente, rate limiting, plausibilidad y moderación. 0003-anti-cheat.md
ADR-004 · Mejoras futuras Redis, tiempo real, microservicios y frontend: disparadores medibles y puntos de extensión. 0004-future-improvements.md
